# SuccubusClinic -えすえすあーる- 公式サイト

サキュバスたちがナースとして働くコンカフェ「SuccubusClinic」をテーマにした VRChat イベント「SuccubusClinic -えすえすあーる-」の公式サイトです。
公開URL：https://succubusclinicssr.github.io/succubusclinic.github.io/
キャスト・お知らせ・動画・集合写真は、**管理画面（/admin）から追加・編集**できます。保存すると数分で自動的にサイトへ反映されます。

```
管理画面（サイトのURL/admin/）
   │  保存
   ▼
GitHub（このリポジトリ） ─ content/ にデータ、uploads/ に画像
   │  自動（GitHub Actions：1〜3分）
   ▼
公開サイト（GitHub Pages）
```

---

## はじめの設定（最初の1回だけ）

### 1. GitHub Pages をオンにする
1. このリポジトリの **Settings → Pages** を開く
2. **Build and deployment → Source** を **GitHub Actions** にする
3. **Actions** タブで「サイトを公開」を開き、**Run workflow** を押す（以降は保存するたびに自動で動きます）
4. 数分後、Settings → Pages に表示される URL（例 `https://ユーザー名.github.io/リポジトリ名/`）でサイトが見られます

### 2. 管理画面用の「アクセストークン」を作る
管理画面へのログインに使う合言葉のようなものです。**人に教えたり、どこかに貼り付けたりしないでください。**

1. GitHub 右上のアイコン → **Settings** → 左メニュー一番下の **Developer settings**
2. **Personal access tokens → Fine-grained tokens → Generate new token**
3. 次のように設定して **Generate token**
   - Token name：`SuccubusClinic 管理画面`（なんでもOK）
   - Expiration：好きな期限（期限が来たら作り直します）
   - Repository access：**Only select repositories** → このリポジトリを選ぶ
   - Permissions → Repository permissions → **Contents：Read and write**
4. 表示されたトークン（`github_pat_` で始まる文字）をコピー（画面を閉じると二度と表示されません）

### 3. 管理画面にログインする
1. `サイトのURL/admin/` を開く（例 `https://ユーザー名.github.io/リポジトリ名/admin/`）
2. **アクセストークンを使用してログイン** を押し、コピーしたトークンを貼り付ける
3. 一度ログインすれば、同じブラウザでは次回から自動でログインされます
   - スマホで使うときは、PCの管理画面の右上のアカウントメニュー →「モバイルでログイン」の QR コードを読むとかんたんです

### 4. 未定のリンク・名前を決める
VRChat グループ・公式 X・ハッシュタグ・会場ワールド名は、`src/build.py` の先頭近く「イベントの基本情報」にまとめてあります。
決まったら、ここだけ書き換えればサイト全体（ヘッダー・フッター・受付ページ・OGP の `twitter:site` など）に反映されます。

| 定数 | 内容 | 未定のあいだ |
|---|---|---|
| `GROUP_URL` | VRChat グループの URL | `"#"`（押しても移動しない仮リンク） |
| `X_URL` | 公式 X の URL | `"#"` |
| `X_ID` | 公式 X の ID（@ なし） | `""` → 「準備中」と表示、`twitter:site` は出さない |
| `HASHTAG` | ハッシュタグ（# なし） | `""` → 「準備中」と表示 |
| `WORLD` | 会場ワールド名 | `""` → 「準備中」と表示 |

## 使い方

左のメニューから種類を選び、**新規作成**（または一覧から選んで編集）→ 入力 → **保存** です。
保存すると GitHub に記録され、**1〜3分ほどでサイトに反映**されます（反映の進み具合は GitHub の **Actions** タブで見られます。緑のチェックで完了）。

### キャスト
| 項目 | 説明 |
|---|---|
| 名前 | 表示される名前 |
| サイトに表示する | 卒業・お休みのときにオフにすると、データを残したまま非表示 |
| 立ち絵 | 背景を透過した PNG（縦長 2:3、例 1023×1537）がおすすめ。サイズは自動で調整 |
| 期生 | ナースの種類（下の表）は期生から自動で決まります。`0` にすると「カルテ準備中」 |
| 役職・担当 | 院長／婦長／主任／シンガー／サブシンガー／ダンサー（複数可） |
| ローマ字表記・キャッチコピー・生年月日・出身・血液型・好物・得意な処置 | カルテ（プロフィール）に表示 |
| イメージカラー | 空なら立ち絵から自動で決まります |
| 並び順 | 同じ期生・同じ役職のなかで、小さい数字ほど前 |

並び順は「期生 → 役職（院長 → 婦長 → 主任）→ 並び順」です。

**ナースの種類**は、管理画面の「設定 → ナースの種類（期生ごと）」で決めます。新しい期生ができたら、ここに追加してください（保存先のファイル名は互換のため `content/settings/maid_types.json` のままです）。

| 期生 | 種類（例） |
|---|---|
| 1期生 | ナース |
| 2期生 | 研修ナース |

### お知らせ
タイトル・日付・カテゴリ（イベント／ナース／メニュー／お知らせ）・本文を入れて保存します。
- 新しい日付の順にトップと NEWS ページに並びます
- サムネイルは「ロゴ」か「画像」を選べます
- 本文の書き方：見出しは `### 見出し`、箇条書きは `- 項目`、リンクは `[NURSESページ](nurses.html)`
- 「下書き」をオンにすると、サイトには出ません

### スケジュール
通常診療（**隔週月曜 21:50〜23:10**。2026年12月7日（月）を起点に14日ごと）は、カレンダーに自動で入ります。ここでは次の2つができます（ここで入れた予定は通常診療より優先されます）。
| したいこと | 入れ方 |
|---|---|
| **診療日を増やす**（特別診療・イベント） | 種類「特別診療・イベント」、日付・開始時刻・終了時刻・カレンダーに出る文字・説明 |
| **診療日を休診にする** | 種類「休診」、その日付（通常の診療日がカレンダーから消えます） |

- 入れた予定は、カレンダー・「次の診療日」のカウントダウン・EVENTS の一覧に反映されます
- 日付をまたぐときは、終了時刻を `24:30` のように書けます
- 予定をやめるときは、その予定を **削除** すれば元どおり（通常診療の日に戻ります）
- 隔週の起点や時刻を変えるときは `src/static/assets/site.js` の `REG`（時刻）・`REG_START`（起点の日）・`REG_EVERY`（間隔の日数）を書き換えます

### 動画
**YouTube の URL を貼るだけ**で、タイトルとサムネイルは自動で取り込まれます（タイトルは自分で書くこともできます）。
タグ（ショート／PV／配信／歌ってみた）と出演ナースを選べます。公開日の新しい順に並びます。

### 集合写真
写真をアップロードすると、トップのスライドと NURSES・MEDIA のギャラリーに出ます。
- トップでは横長（2:1）に自動で切り抜かれます。「残す位置」で上・中央・下を選べます
- 「並び順」の小さい数字ほど前（1枚目がトップに最初に出る写真）
- トップだけ・ギャラリーだけに出すこともできます

## 困ったとき
- **保存したのに反映されない**：GitHub の Actions タブを確認。赤い×のときは、開くと理由が英語で出ています（多くは画像の形式。PNG・JPG・WebP を使ってください）
- **ログインできない**：トークンの期限切れか、権限（Contents：Read and write）が足りません。作り直してください
- **消してしまった**：GitHub にすべての履歴が残っているので、元に戻せます

## 中身（開発者向け）
| 場所 | 内容 |
|---|---|
| `content/` | 管理画面で編集するデータ（1件＝1つの JSON ファイル） |
| `uploads/` | 管理画面でアップロードされた画像（元の画像） |
| `src/pages/` | 各ページのひな形 |
| `src/static/` | CSS・JavaScript・ロゴなど、そのまま公開するファイル |
| `src/build.py` | サイトを組み立てるスクリプト（画像の縮小、YouTube のサムネ取得も）。先頭に未定のリンクなどの定数 |
| `admin/` | 管理画面（[Sveltia CMS](https://sveltiacms.app/)）とその設定 `config.yml` |
| `.github/workflows/deploy.yml` | 保存のたびに組み立てて GitHub Pages に公開する設定 |

手元で組み立てる場合：
```bash
pip install -r requirements.txt
python src/build.py        # _site/ に公開用のサイトができます
```
